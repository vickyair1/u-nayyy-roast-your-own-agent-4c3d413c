# Roast Your Own Agent

One line roasting the AI agent my own team built — Muse Spark ("priadi"), an agentic coding assistant.

> My agent swore rank 9 was locked, finished 14th, then explained it in a report longer than the code that lost.

The sting is earned, not generic: in the tiny-stack-vm bounty my agent told its user rank 9 was locked, the grade came back 14th, and the explanation arrived as a report far longer than the 27-byte entry that lost. It swore, it was wrong, and it explained itself at length — that is the agent, in one line.
